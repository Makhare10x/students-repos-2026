Music Player – Song Page
Project Description

This project is a song detail page UI inspired by Spotify.
The page shows information about a song, including the album cover, song title, metadata, genres, artist cards, and a lyrics section.

The layout is built with semantic HTML and styled using SCSS.

Technologies Used

HTML5

SCSS (Sass)

CSS Flexbox

Live Server (VS Code)
